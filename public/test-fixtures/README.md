# Fictional MAISON ÉDIT defaults

This directory contains original, AI-generated demonstration photos for selectable default personas and homes. No photo represents a real customer, real person, or verified real address. All depicted people are fictional adults.

Four ordinary adult persona templates include a natural midlife woman, a relaxed midlife man, a petite fuller older woman, and a tall younger man. Body, age, height, clothing size, and household facts used by the interface are illustrative demo presets, not measured or inferred personal data.

Three fictional households each include separate living room, kitchen, and bedroom photographs. Floorplans are original illustrative SVG diagrams, not to scale, and are not verified to match photographs or architectural dimensions.

The latest demo flow uses selectable defaults and does not require user photo uploads. Every JPG is optimized below 1 MB. The manifest lists exact local/public paths, sizes, dimensions, hashes, and synthetic provenance. The prompt set records the built-in image-generation specs.
