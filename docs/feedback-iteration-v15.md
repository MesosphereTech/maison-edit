# Feedback iteration: conversation, try list and gifting

This iteration keeps the existing private Sites project and local demo boundaries.
No real store is contacted; no provider request, payment, order or real reservation
is created merely by browsing, selecting wrapping or adding a try-list item.

## Conversation

- Every bubble/global close, minimize and history close folds to one right-edge
  ÉDIT launcher. A click, Enter or Space opens the same conversation again.
- Drafts, complete dialogue, reading position and full-drawer mode remain local
  to the current visit. New messages and attention do not reopen a minimized UI.
- Product inspection is signalled by the central product-open path, covering card
  images/names, outfit components and conversation product links. The compact
  dialogue is half-transparent and moves clear of the product visual.
- Normal motion shows an anchored gold contour lap, a coherent particle route,
  a single arrival edge accent and progressive phrases. Reduced motion uses
  immediate readable copy without travel effects.

## Outfit components

Linked outfit images now sit inside the large visual, below the top-right swap
inset. Each image is 36px within a 44px keyboard/touch control. Accessible names
include exact catalogue identity and current fictional ownership.

## Store try list

The explicit catalogue action adds a product to the local store try-on list, or
experience list for non-clothing. Current fictional profile templates provide
supported clothing/shoe sizes automatically; unsupported matching stays pending.
A submitted request is separate from a demo merchant acknowledgement. Only a
confirmed ready state can be described as reserved within the local simulation.
Try-list entries never create purchase-history ownership.

## Gift selection

Gift intent is explicit. Three locally generated wrapping concepts can be chosen
with optional recipient, occasion and card message. Gift size belongs to the
recipient and never defaults to the shopper. Unknown recipient size remains
pending. Non-self apparel uses a clearly labelled clothing-model presentation,
with the selected wrapping concept, rather than implying the shopper wears it.

Packaging provenance is recorded in gift-packaging-provenance/manifest.json.
All images are illustrative concepts, without real service or availability claims.
