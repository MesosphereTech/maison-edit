# MAISON ÉDIT 云端首稿

这是 JX Labs Shanghai 的原创百货购物概念原型。MAISON ÉDIT 是暂定展示名。

体验地址：https://maison-edit-jx.colinjin540439.chatgpt.site

当前为本人私有预览，需以拥有该站点的 ChatGPT 账户登录。它不是已公开给比赛评委的提交链接。

## 建议体验顺序

1. 页面首屏直接显示所选普通成年测试人物，默认是一位自然、日常的虚构家庭女性。无需上传任何私人照片。
2. 在“默认测试场景”中直接选择四种人物/身形模板、三种住宅/房型以及客厅、厨房或卧室，图片、推荐排序和默认尺码会随选择变化并自动保存。需要更细的风格、尺码、预算控制时，再打开“我的人物与空间”。
3. 浏览“发现”，切换女装、男装、配饰和家居，输入关键词或预算。信息流按当前示例目录渐进加载，目录有限，并非无限生成新图片。
4. 打开私人导购，试试“预算 2000 以内”“温暖的家居”“更省预算的替代款”。本版导购是已明确标注的本地规则演示，会实际改变页面筛选。
5. 打开商品，选尺码、颜色和数量，加入试选清单；可以保存单品或整组搭配。
6. 在试选清单里选择未来日期、时段和希望分享的资料，确认演示预约，查看楼层与柜位路线。
7. 从页脚进入“商户工作台”，改变库存、准备状态或提出替代款，再回到顾客端查看同步变化并接受或拒绝。
8. 点击声音按钮开启原创合成环境音乐，试试音量、静音、手机布局和 EN/中文切换。

## 已实现与尚未接通

已实现的是可操作的零上传演示闭环：四位普通成年人及身形默认模板、三组住宅与示意房型、九张独立客厅/厨房/卧室参照图、即时推荐排序、人物/空间档案、浏览筛选、导购动作、收藏与清单、演示预约、示意路线、商户备货/替代反馈、背景音乐及本浏览器内保存。它没有向任何真实商场下单、预约或发消息。

人物和房间图片为预先生成的原创虚构素材，身高和尺码是示例模板，不是从图中测量出来的。商品、品牌、价格、库存和商场均为原创示例。测试界面没有私人照片上传入口，默认场景图不是根据用户照片或所选商品即时生成的试衣、房间改造或视频结果。图中的服装和家具不是目录商品，示意房型没有经过真实尺寸核验。旧版曾在此浏览器保存且获同意的照片会隐形保留，不用于测试展示或 AI 请求，可在“偏好与数据”中主动移除。

已写好服务端 Gemini 导购、可选文字生成场景图片适配代码，以及 Cloud Run 容器部署文件，但尚未配置或调用真实 Google 服务。另已接入受限的临时 OpenAI GPT CLI 测试适配器，只允许固定虚构场景和目录数据；本次实际启动测试受到运行环境只读状态限制，尚未产生真实 GPT 推理或图像分析，不能把安装 CLI 或模拟测试当作连接成功。页面按真实后端状态分别显示本地演示、未验证连接测试、已验证 AI 回复或不可用，当前静态预览保持本地演示，实时试衣与空间重绘仍未提供。上线真实 AI 需要合法配置服务端密钥与可用模型，完成费用、身份验证、隐私和实际调用测试。不能把通过模拟测试解释成已接通 Gemini。

顾客与商户目前共享同一浏览器中的演示数据，没有跨设备账户、数据库或真实库存/预约系统。车配、健康食品、妆造、实时个人海报/视频等完整构想尚待后续开发。
